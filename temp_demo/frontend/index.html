Why Accuracy Is Not Reported

This system is an unsupervised anomaly detection engine. The source dataset does not contain verified fraud / non-fraud ground-truth labels. Therefore, conventional supervised metrics such as accuracy, precision, recall, and F1-score cannot be validly calculated without introducing fabricated labels.

Instead, the model is evaluated using out-of-sample stability, anomaly-rate consistency, signal overlap (Jaccard similarity), and repeatability across random 80/20 splits.
