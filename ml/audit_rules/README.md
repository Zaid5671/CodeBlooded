# Deterministic Audit Rules Engine

Statutory compliance, delay SLA, vendor concentration, and eligibility audit rules.

## Modules
- `delay/`: Recommendation-to-sanction approval delay SLA rules
- `statutory_compliance/`: Statutory guideline compliance checkers
- `eligibility/`: Prohibited asset negative-list & private beneficiary screening
- `vendor_risk/`: Herfindahl-Hirschman Index (HHI) vendor concentration analytics
- `fund_utilization/`: Fund utilization velocity checkers
- `evidence.py`: Audit evidence record generator
