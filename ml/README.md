# Machine Learning Models (M1–M5)

This directory contains the machine learning models and analytical scoring engines for the MPLADS Audit Intelligence Platform.

## Models
- `model_1_cost_anomaly/`: M1 — Anomalous Cost Estimate & Cost Overrun Detection Engine (Isolation Forest ML + Peer IQR)
- `model_2_duplicate_work/`: M2 — Duplicate Work / Record Linkage Engine (TF-IDF Cosine Similarity + Geographic Candidate Blocking)
- `model_3_expenditure_anomaly/`: M3 — Expenditure & Fund Disbursement Anomaly Detector
- `model_4_forecasting/`: M4 — Empirical Expenditure Forecasting Engine (6-Month Rolling Average)
- `model_5_audit_priority/`: M5 — Multi-Signal Risk Aggregator & Audit Priority Triage Engine
